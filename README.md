# Astrosnek

Astrosnek is a Python-based astrophotography processing pipeline focused on
automating image calibration, quality analysis, alignment, stacking, and
future post-processing.

## Current Features

- Convert Sony ARW files to FITS
- Detect stars using DAOStarFinder
- Measure image quality
- Rank frames
- Interactive FITS viewer
- JSON analysis reports
- Docker-based execution

## Planned Features

- Dark/Bias/Flat calibration
- Image alignment
- Image stacking
- Automatic best-frame selection
- Command-line launcher
- Plate solving
- Image export

## Requirements

- Docker
- Python 3.12+
